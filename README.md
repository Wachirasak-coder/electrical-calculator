# โปรแกรมคำนวณสายไฟ No.1

เครื่องคำนวณสายไฟฟ้าแบบเว็บ สถิต ภาษาไทย สำหรับออกแบบเบื้องต้นตามมาตรฐานการติดตั้งทางไฟฟ้าสำหรับประเทศไทย **วสท. 022001-22** (EIT 2564), IEC 60364, IEC 60502, IEC 60228 และ EIT 022013 (ระบบโซลาร์)

โดย [Electrical Engineer No.1](https://www.facebook.com/ElectricalEngineerNo.1)

ผลบนหน้าเว็บใช้สูตรเดียวกับสมุดงาน `โปรแกรมคำนวณสายไฟ No.1` ช่องสีเหลืองคือข้อมูลนำเข้า ผลลัพธ์อัปเดตทันทีเมื่อแก้ตัวเลขหรือเลือกจากรายการ และมีป้าย **ผ่าน PASS / ไม่ผ่าน FAIL**

> ผลคำนวณใช้ประกอบการออกแบบเบื้องต้นเท่านั้น ผู้ออกแบบต้องตรวจสอบกับมาตรฐาน ข้อมูลผู้ผลิต และวิศวกรผู้ได้รับใบอนุญาตต้องตรวจก่อนนำไปใช้จริง

## ฟังก์ชันทั้ง 18 รายการ

1. พิกัดกระแส LV — โหมดย้อนกลับ จากขนาดสายหา Iz หลัง Ca และ Cg
2. ขนาดสาย 1 เฟส
3. ขนาดสาย 3 เฟส
4. วงจรมอเตอร์ — FLC จากตาราง × ตัวคูณ DOL 1.25 หรือ Star-Delta 0.91
5. สายเมนหม้อแปลง — Ib = kVA × 1000 / (√3 × V)
6. สายแรงดัน MV พร้อมอ้างอิงตาราง 5-38 duct bank
7. แรงดันตกตลอดเส้นทาง สูงสุด 5 ช่วง (ตาราง ฐ และสูตร R, X)
8. ท่อร้อยสาย ตามเกณฑ์ตาราง 5-3
9. รางเดินสาย เกณฑ์บรรจุไม่เกิน 20%
10. รางเคเบิลกลุ่มที่ 7 แบบชั้นเดียว
11. สายดิน PE ตามตาราง 4-1 / IEC 60364-5-54 Table 54.2
12. ตู้ MDB เลือก AT/AF
13. กระแสลัดวงจรที่ตู้ MDB
14. กระแสลัดวงจรที่ตู้ DB (ใช้ระยะในตารางที่สั้นกว่าอย่างอนุรักษ์นิยม)
15. ปรับปรุงเพาเวอร์แฟกเตอร์ Qc = P (tan φ1 − tan φ2)
16. โซลาร์ On-grid ตาม EIT 022013 ภาคผนวก ฌ
17. โซลาร์ Off-grid
18. ขนาดกล่องไฟฟ้า ตาราง 6.4

หน้าแรกมีช่องค้นหา แต่ละเครื่องคิดเลขเปิดด้วยลิงก์ `#1` ถึง `#18` เช่น `#3` คือขนาดสาย 3 เฟส

ค่าโดยประมาณที่ต้องตรวจ (ค่า X, R70/R90 ที่คำนวณจาก IEC 60228, ตารางสายดินสำรอง, ข้อจำกัดของ THW-A) แสดงเป็นโน้ตในหน้าที่ใช้ค่านั้น และรวบรวมไว้ที่หน้า [ตรวจสอบค่า](#notes)

หลังจากเปิดเว็บครั้งแรก เซอร์วิสเวิร์กเกอร์จะเก็บไฟล์ไว้ใช้แบบออฟไลน์ได้เมื่อไม่มีเครือข่าย

## เปิดบน GitHub Pages

ไซต์นี้เป็นไฟล์ HTML/CSS/JS ล้วน ไม่มีขั้นตอนบิลด์และไม่มีเซิร์ฟเวอร์

รีโพนีตั้ง GitHub Pages ไว้แล้วแบบ **Deploy from a branch**: สาขา `main` โฟลเดอร์ `/` (root) หลังเมิร์จเข้า `main` เว็บจะอยู่ที่

**https://wachirasak-coder.github.io/electrical-calculator/**

ไม่ต้องเปลี่ยนการตั้งค่า Pages เพิ่ม ถ้าหน้าเก่ายังขึ้นอยู่ ให้รอสักครู่แล้วรีเฟรชแบบไม่ใช้แคช

ถ้า Pages ถูกปิดไว้ ให้เปิดใหม่ดังนี้

1. เปิด Settings ของรีโพ แล้วเลือก Pages
2. ที่ Build and deployment เลือก **Deploy from a branch**
3. Branch เป็น `main` และโฟลเดอร์เป็น `/ (root)` แล้วกด Save

ไม่ต้องสลับไปใช้ GitHub Actions เป็นตัว deploy เพราะโหมด branch/root เผยแพร่ไฟล์ในรีโพตรง ๆ อยู่แล้ว เวิร์กโฟลว์ในรีโพมีหน้าที่รันเทสต์เท่านั้น

เปิดเครื่องคิดเลขพื้นฐานเดิมได้ที่ https://wachirasak-coder.github.io/electrical-calculator/eleccalc/
